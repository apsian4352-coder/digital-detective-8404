## 4. My understanding

### Task 1.1 — Tracing an Activity Using IPOS
I traced what happens when I write and save a project report on my laptop:

| Stage | What happens in my example? | Possible hardware / component |
| :--- | :--- | :--- |
| Input | I type words using the keyboard. | Built-in keyboard |
| Processing | The CPU takes key signals and stores text in memory. | Apple Silicon CPU and RAM |
| Output | The text shows up on my screen as I type. | Laptop screen |
| Storage | When I press Command+S, the file saves to my SSD. | Internal SSD |

**How it flows:** My typing gives input, the CPU and RAM process it, the screen shows the output immediately, and saving puts it into persistent storage so it is not lost when I turn off the laptop.
