## How to Run the Number Converter

1. Open your terminal and go to the Mission 05 folder:
   ```bash
   cd mission-05-numbers-data
   ```
2. Run the script:
   ```bash
   python3 number_converter.py
   ```
3. Type any positive number to get its binary and hex values.
